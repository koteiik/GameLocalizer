# Совместимый режим

`CompatibleReplacement` — основной рекомендуемый способ применения. GameLocalizer заменяет значения в физическом файле, из которого извлечены строки. Например, `BepInEx/Translation/en/Text/dialogue.txt` остаётся в слоте `en`, даже если AutoTranslatorConfig содержит `Language=ru`. Ключи, комментарии, порядок, дубликаты, разделители, кодировка, BOM и переводы строк сохраняются адаптером. Config не изменяется. Новые RU-каталоги не создаются.

Scan-база хранит `PhysicalSourceFile`, `LocalizationSlot`, `AdapterType` отдельно от исходного и переведённого текста. Старые базы мигрируют без удаления строк. Ключ не передаётся провайдеру; ручной перевод имеет приоритет над повторным переводом и памятью.

Resolver проверяет поддерживаемый адаптер и содержимое файла, сопоставляет путь с доступным AutoTranslatorConfig. Config служит дополнительным свидетельством, а не источником целевого пути. Статическое сканирование не может доказать, что конкретный fallback или слой используется работающей игрой. Если найдено несколько слоёв, пользователь проверяет физические файлы в Preview. Неопределённый слот не подменяется `ru`.

Перед записью сохраняются оригинальные байты и SHA256. Manifest содержит путь, backup object, original/applied hashes, адаптер, режим, слот, encoding, BOM и line endings. Повторное применение после свежего scan обновлённого файла создаёт новый оригинал и сохраняет прежнюю запись в History. Restore блокируется, если текущий файл изменён извне. Старый оригинал не восстанавливается поверх новой версии игры.

Restore сохраняет manifest и backup. Cleanup восстанавливает оригиналы, удаляет только доказуемо созданные файлы и пустые каталоги, затем удаляет собственные backup objects и manifest. Чужие файлы, включая чужое содержимое backup-каталога, остаются. Translation Memory, модели и настройки сохраняются.

`SeparateTargetLocale` оставлен в enum для будущего расширенного режима; попытка применения этого режима пока отклоняется. Шрифты не изменяются: выводится только предупреждение о возможном отсутствии кириллицы.

Регрессии: CompatibleModeTests, BepInExLocalizationTests, CleanupTests. Локальная сборка, тесты, publish и установка выполняются через `scripts/dev-install.ps1`; публичная версия и GitHub-публикации не меняются.
