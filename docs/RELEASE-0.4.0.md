# GameLocalizer v0.4.0

Стабильная фиксация текущей рабочей версии для Windows x64.

- Офлайн-перевод EN → RU и постоянная Translation Memory.
- Постоянный кэш анализа игры: автоматическое восстановление результатов, переводов, ручных правок и выбора строк; инкрементальное обновление изменённых, новых и удалённых файлов.
- Поддержка BepInEx/XUnity `key=value`, включая повторяющиеся ключи и существующие языковые слоты.
- Резервные копии, восстановление и «Убрать» с сохранением пользовательских данных и переводов.
- Классификация UI/Short UI и read-only поиск кандидатов в Unity-ресурсах с безопасным ограниченным исследованием бинарных данных.
- Диагностический Apply Trace, отчёты применения, сохранение Original после Apply и обработка пустых переводов.

Установщик и обновление сохраняют `analysis.db`, `memory.db`, модели, настройки, глоссарий и журналы в `%LOCALAPPDATA%\GameLocalizer`. Офлайн-модель загружается отдельно через настройки и не включена в архив.

Ограничения: запись поддерживается пока не для всего Unity UI. Сжатые bundle-контейнеры могут оставаться неподдерживаемыми, а read-only исследование ограничено и не доказывает отсутствие текста. Покрытие dialogue/scenario ещё не завершено; машинный перевод требует проверки.

Runtime UI Collector в этот релиз не входит; работы над ним не начинались.

SHA256 файлов опубликованы в `SHA256SUMS.txt`; статус подписи установщика указан в `installer-manifest.json`.
