# GameLocalizer v0.5.0

Стабильная фиксация текущей рабочей версии для Windows x64.

- Переработанный UI: sidebar navigation, библиотека с локальными Steam-обложками и иконками, dockable панель выбранной игры и одна основная кнопка по текущему состоянию.
- Runtime UI Collector для поддерживаемых Unity Mono / BepInEx 5 игр: сбор отображаемых строк, контекстов и импорт результатов в GameLocalizer.
- Предварительная генерация Runtime Translation Dictionary. Игровой модуль использует готовый локальный словарь для замены поддерживаемых UI/dialogue строк без сети, модели и запущенного GameLocalizer во время игры.
- UI glossary, контекст, ручные исправления, preview и пересчёт Runtime переводов перед обновлением словаря.
- Завершение translation jobs, отображение частичного результата и ошибок, сохранение результата Apply между разделами и перезапусками, повтор только применения и единое окно подтверждения.
- Проверка записанных файлов, manifest/ownership и резервных копий перед Applied; обнаружение внешних изменений. Уже готовые принадлежащие GameLocalizer файлы проверяются без повторной записи. Существующие Restore/Cleanup и механизмы безопасного обновления сохранены.

**Ограничения:** Runtime/dialogue coverage зависит от конкретной игры и может быть неполным. Collector предназначен для Unity Mono с существующим BepInEx 5; IL2CPP не поддерживается. Поддерживаемые dialogue hooks исследованы для AI Shoujo. Наличие синтетических regression tests не доказывает полное покрытие, отсутствие конфликтов с другими модами или характеристики FPS в каждой игре. Машинный перевод требует проверки; неизвестные строки остаются в исходном виде.

Обновление сохраняет `memory.db`, `analysis.db`, Models, Settings, Glossary, Logs, RuntimeDictionary и остальные пользовательские данные в `%LOCALAPPDATA%\GameLocalizer`. В пакеты не включены пользовательские данные, модели или DLL игры/loader. Офлайн-модель загружается отдельно через настройки.

Пакеты: штатный `GameLocalizer-Setup.exe` и portable `GameLocalizer-win-x64.zip`. SHA256 опубликованы в `SHA256SUMS.txt`; статус подписи установщика указан в `installer-manifest.json`.
