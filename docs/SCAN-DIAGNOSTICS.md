# Local scan crash correction

The old installed implementation reproduced `ArgumentException: output char buffer is too small` on `E:\steam\steamapps\common\AI-Shoujo\StudioNEOV2_Data\sharedassets2.assets`. The stage was `UiResourceDiscovery.StringsAsync`, calling UTF-8 `Decoder.GetChars` with a 65536-byte input and a 65536-char destination. Pending malformed multibyte input from the previous chunk could produce replacement characters in addition to the next full chunk. The complete original exception and stack are retained in `artifacts/dev/scan-runtime/legacy-decoder-fault.json` and `%LOCALAPPDATA%\GameLocalizer\Logs\ScanDiagnostics\AIShoujo_legacy_decoder_fault_20261002.json`.

Unity binary resources now receive read-only candidate inspection. Only delimiter-separated runs of at most 1024 bytes are strictly decoded as UTF-8, preserving candidate bytes across read boundaries. Invalid or incomplete runs are counted and rejected. ASCII UTF-16LE candidates are inspected separately. Files are limited to 64 MiB and 2000 candidates; compressed UnityFS/UnityWeb/UnityRaw containers are marked unsupported rather than decoded. This is evidence discovery, not a Unity object parser or proof that missing text is absent.

Primary supported text scanning completes before optional Unity discovery. The previous preview/session remains available until a successful primary replacement. Per-file discovery exceptions retain full path, stage and stack in scan JSONL logs. Optional failures produce PARTIAL status and preserve the supported rows. The UI offers «Открыть журнал» and a short error message; the normal application log also includes complete exception stacks.

Regression tests cover ASCII, Cyrillic, Japanese, mixed languages, emoji, a UTF-8 sequence split at 65536 bytes, invalid/incomplete sequences, large text, oversized binary runs, readable binary islands, unsupported bundle headers, the real legacy overflow mechanism, preserved BepInEx rows on optional failure, and retained previous rows on primary failure.

`tools/GameLocalizer.ScanProbe` is a read-only diagnostic CLI referencing installed assemblies. Rebuild it after installation; it rejects an Infrastructure DLL hash differing from the installed DLL. It does not launch a second GUI or modify game files, translation memory, jobs or settings. Its scan evidence is saved in `artifacts/dev/scan-runtime/installed-scan.json`.
